Willkommen im Admin-Bereich

Hier können Sie die Grundeinstellungen der Website verwalten. Ändern Sie Kontaktdaten, Öffnungszeiten, Mitgliedsbeiträge und mehr – ganz einfach und ohne technische Kenntnisse.

Schnellanleitung:

  • Wählen Sie links den Bereich, den Sie bearbeiten möchten
  • Ändern Sie die Einträge in den Formularfeldern
  • Klicken Sie auf „Änderungen speichern" oben rechts
  • Die Website wird automatisch aktualisiert
